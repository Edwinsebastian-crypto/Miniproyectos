FUNDAMENTOS WEB: HTML & CSS

1. ¿Qué es CSS?

CSS (Cascading Style Sheets o Hojas de Estilo en Cascada) es el lenguaje de diseño utilizado para controlar la apariencia, formato y presentación visual de los documentos estructurados en HTML. Se encarga de definir los colores, fuentes, espaciados, alineaciones y la disposición de las pantallas (layouts) en los navegadores.

2. Importancia de HTML y CSS

HTML y CSS son los dos pilares fundamentales del desarrollo web moderno. Su importancia radica en la separación de responsabilidades:

  • HTML crea el esqueleto: Define qué elementos existen en la página (textos, imágenes, formularios).
  • CSS crea la experiencia: Convierte un documento plano de texto en un entorno visualmente atractivo, intuitivo, accesible y estético para el usuario final. Sin CSS, la web actual sería completamente ilegible.

3. Ventajas y Desventajas

Ventajas:
  • Estandarizados y compatibles con todos los navegadores modernos.
  • Fáciles de aprender e implementar.
  • CSS permite reutilizar código aplicando un solo estilo a múltiples pantallas.
  • Excelente rendimiento de carga en la web.
Desventajas:
  • HTML/CSS por sí solos crean páginas estáticas (necesitan JS para lógica compleja).
  • CSS puede volverse difícil de mantener en proyectos gigantescos.
  • Inconsistencias visuales menores entre navegadores antiguos si no se tiene cuidado.

4. Selectores CSS y Ejemplos Sencillos

Los selectores le indican a CSS a qué elementos del HTML debe aplicar los estilos. Existen diferentes tipos:

  • Selector Básico (Etiqueta): Afecta a todas las etiquetas de ese tipo en la página.
  • Selector de Clase (.): Se usa para dar estilo a varios elementos específicos. Se define en HTML con class="".
  • Selector de ID (#): Es único. Solo se debe aplicar a un único elemento en toda la página. Se define con id="".

Ejemplo práctico de conexión:

<!-- HTML -->
<p>Párrafo básico de etiqueta</p>
<p class="texto-azul">Párrafo con clase</p>
<p id="parrafo-unico">Párrafo con ID único</p>
/* CSS Asociado */
p { color: gray; } /* Todos los párrafos serán grises */
.texto-azul { color: blue; font-weight: bold; } /* Aplica solo a la clase */
#parrafo-unico { color: orange; font-size: 20px; } /* Aplica solo a este ID */

5. Tabla Investigativa de Propiedades CSS

Listado de las propiedades más utilizadas en el desarrollo profesional para controlar estilos y estructuras:

Propiedad CSS Acción / Descripción
color Modifica el color del texto del elemento.
background-color Define el color de fondo de un contenedor o elemento.
font-size Establece el tamaño de la tipografía (en px, rem, em).
font-family Asigna la familia tipográfica o tipo de letra.
margin Crea espacio por fuera de los límites del elemento (separación externa).
padding Crea espacio por dentro del elemento (distancia entre el contenido y su borde).
border Dibuja una línea alrededor del elemento (grosor, estilo y color).
width / height Establecen el ancho y el alto del elemento respectivamente.
display Controla el comportamiento de renderizado del elemento (block, inline, flex, grid, none).
position Define el método de posicionamiento en el espacio de la pantalla (static, relative, absolute, fixed).
